    @agents

    For AI agents

    AI agents can make up references that look real. Ibis’s MCP server lets an agent search your references, show their fields, format citations and find styles, and nothing else: it’s read-only and doesn’t share notes or attachments. Add this command to your agent’s MCP setup:

    ibis mcp

    @install

    Install the command

    Homebrew on Mac or Linux:

    brew install ibiscite/tap/ibis

    On Windows, or without Homebrew, download the command for your system from the release page. Command line guide.

Command line

Everything the picker does, the ibis command does too, from the same engine.

The examples run against sample.bib, three invented references, and show exactly what Ibis prints.

@terminal

Search and cite from a terminal

{{terminal}}

Ibis prints to standard output and errors to standard error; it never copies by itself. Pipe it to pbcopy, clip or wl-copy to copy.

@shorthand

Type it the fast way nightly

In the picker, put the details right in the search: a word before the reference, the reference, then a page.

    Lantern gardens follow imaginary cities [@fen2023clouds, chap. 2]⁠.

    Lantern gardens follow imaginary cities [@reed2025maps, pp. 12–14]⁠.

    Lantern gardens follow imaginary cities [see @vale2024lanterns, p. 33]⁠.

    Lantern gardens follow imaginary cities [see @vale2024lanterns, p. 417]⁠.

    Lantern gardens follow imaginary cities [see @vale2024lanterns, p. 417]⁠.

    @agents

    For AI agents

    AI assistants sometimes invent references that look real. Connect Ibis so your assistant can use your real library: search your references, read their details, find citation styles, and format citations and reference lists in any style. It’s read-only: it cannot change your library or read notes or attachments.

    Try asking:

    “Find my papers on lantern gardens and cite the Vale one in APA, page 12.”

    First, install the ibis command and choose your library in Ibis. Then choose your assistant below to connect it once.

    In Claude Desktop, open Settings › Developer › Edit Config, add this to claude_desktop_config.json alongside any existing servers, then fully quit and reopen Claude.

    {{agent-claude-config}}

    For Claude Code, paste this into your computer’s terminal and press Enter:

    {{agent-claude-command}}

    In ChatGPT desktop, open Settings › MCP servers › Add server › STDIO and enter the fields below. ChatGPT on the web cannot start programs on your computer.

    {{agent-chatgpt-fields}}

    To connect Codex, paste this into your computer’s terminal and press Enter:

    {{agent-codex-command}}

    Click Add to Cursor and confirm the setup in Cursor.

    Add to Cursor

    Click Add to VS Code and confirm the setup in VS Code.

    Add to VS Code

    To connect Gemini CLI, paste this into your computer’s terminal and press Enter:

    {{agent-gemini-command}}

    Your assistant starts Ibis by itself; you never type ibis mcp into the chat.

    Ibis reads your library on your computer; only reference details and citations go to your assistant, which may send them to its provider. Privacy and plugin notice.

    @install

    Install the command

    Homebrew on Mac or Linux:

    brew install ibiscite/tap/ibis

    On Windows, or without Homebrew, download the command for your system from the release page. Command line guide.

# 0038 One window that unfolds

The picker is a launcher first: type, see references, Enter. The citation line
holds the actual output as tokens; citation details open from a token
([0045](0045-citation-line-token-field.md)) in a drawer above the delivery bar.
Warning details use the side panel. Search, the list and the delivery bar
(the citation, the one action and More) remain available without a second
workspace to learn; only the PDF reader opens a window of its own.

The planned PDF reader opens in its own read-only window, sized so a portrait
page is readable (amended 2026-11-25 by [0036](0036-reader-trust-boundary.md)).
Esc closes it and returns to the picker. Show PDF remains hidden in the running
app until that boundary is implemented and qualified.

Choosing pages is explicit: thumbnails, range selection or Cite This Page.
Scrolling never changes the citation's page. Printed labels and physical PDF
indices remain distinct; unknown labels ask for confirmation.

Only controls that act need visual weight. Rows have no decorative plate;
the bar's action is quiet text with an accented Enter cap; Settings cards
separate by fill. Repeated library lines and reference titles add no control.

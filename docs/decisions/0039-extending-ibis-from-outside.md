# 0039 Extending Ibis from outside

Engine crates are AGPL-3.0-or-later, including when linked by another program.
The published contract and thin clients that only talk to `ibis`, JSON-RPC or
MCP are MIT. Independently published files carry their SPDX identifier so an
integration's licence boundary is explicit.

Official packages use [0046's names](0046-official-names-and-listings.md).
Packages are published with real functionality, never as empty placeholders.
Integration plans live in [the roadmap](../../ROADMAP.md).

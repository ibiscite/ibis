# 0050 The menu bar menu

Ibis uses a native menu on every system. It offers checked library choices
inline, and each library problem leads to its fix. Watched files need no
Reload command. The bird's accessible title speaks library state; Windows
uses the tray tooltip.

On macOS, dropping text on the bird searches for it; supported library files
open as libraries. The bird raises its head only for accepted drops. PDFs wait
for the reader and lookup rules. Updates are event-driven, without hidden
polling, animation or extra permissions.

The menu copies rather than pastes: it cannot prove the caret's destination.
Planned Copy Again uses the current app's last five references and remembered
format, excludes closed libraries and obeys Forget Recent Citations. It waits
for [engine citation sessions](0052-engine-owns-library-and-citations.md).

The bird is never the only way to reach an action. No custom menu card, tinted
icon, default text/figures in the bar or private layout APIs.

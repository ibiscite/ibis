# 0027 Process until 1.0 (with 0011, 0015 and 0017)

Superseded by [0049](0049-local-gate.md) for how changes merge and are checked.

Still in force (maintainer, 2026-10-28 and 2026-11-02): agents have standing
engineering and merge authority over the maintainer's own work, with no
compatibility code. Stable releases wait for the maintainer's one-click
approval. Approved plans are recorded the same day in the repository, never
only in a chat. The website demo stays functionally aligned with the released
app. Related changes go in one pull request, and a separate review of the final
head is needed only for the updater, release signing and publishing, CI
permissions and security boundaries.
